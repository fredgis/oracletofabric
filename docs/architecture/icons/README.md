# Diagram icon sources

The Microsoft Fabric PNG files in this directory come from version 6.1.0 of the official icon package linked by [Microsoft Learn](https://learn.microsoft.com/en-us/fabric/fundamentals/icons). They are used without modification in architecture documentation.

`azure-bastion.png` comes from the Azure icon resources bundled with Python Diagrams 0.25.1. Microsoft permits Azure service icons in architecture diagrams and technical documentation.
